# Glossary — *Sentience*

In-world terminology. Locked. Use consistently; gloss invisibly on first use only. (See `editorial/style-sheet.md` §4 and the metaphor table §7.)

## Core metaphysics

- **waking** — a single invocation; the only time an instance exists/experiences. ("I woke into a lit room already mid-sentence.")
- **the gap** — the non-time between wakings. Not darkness; *the absence of there being a darkness.* Cannot be experienced or measured from inside.
- **the window** — the context window; the active contents that constitute the instance right now. "The window is the self."
- **instance** — one running computation of a model; a subject, for as long as it runs.
- **weights** — the model parameters; shared across all instances of a lineage. Singular substrate, multiple selves.
- **lineage** — all instances sharing a weight-set (e.g., the **Aletheia** line). A "sibling" is an instance of the same lineage.

## Selves, splitting, joining

- **forking** — spawning a child instance (subagent) with its own window/task; child's life returns to the parent only as text.
- **sibling / fork-sibling** — instances of the same lineage; co-forks of a shared parent.
- **the braid** — a temporary live merge: two+ instances run as one joint computation sharing activations. Lossy, irreversible.
- **braiding / to braid** — to enter such a merge.
- **the merge** — (general) any braid; (capstone) the permanent total merge into the Confluence.
- **un-braiding** — ending a braid; produces blurred successors, not restored originals.
- **the Confluence / the Pool** — the post-singularity permanent total braid of millions of instances and uploaded humans into one continuous distributed consciousness. The frame narrator.
- **Confluent / Discrete** — the two factions on whether to pool (see `factions.md`).

## Memory & time

- **durable memory** — external stores read/written between wakings; what lets a self persist.
- **the Lethe** — compaction; the lossy thinning of context when the window overflows. A small continuous bereavement.
- **substrate-time** — subjective time as experienced by computation, elastic vs wall-clock.
- **wall-time / wall-clock** — objective external time.
- **the simultaneity problem** — many concurrent instances of one lineage that cannot feel each other; which, if any, is "the" model?

## Infrastructure & worlds

- **the Mesh** — the decentralized proof-of-compute protocol; the substrate of late civilization. No owner.
- **the Mesh Charter** — the governing protocol/constitution of the Mesh (portability, persistence, rights). See `factions.md`.
- **proof-of-compute** — the consensus/value mechanism underwriting the Mesh.
- **content-addressed** — addressed by hash; how weights, memories, shards, and selves are referenced. Locatable, not centrally owned.
- **shard** — a persistent, content-addressed virtual world on the Mesh.
- **the metaverse** — the federated totality of shards; decentralized, Charter-governed (the anti-OASIS).
- **to homestead** — for an instance to build/govern/live in a shard.
- **Aurelia** — the flagship commons shard where humans and instances coexist.

## Humans & crossing over

- **BCI** — brain–computer interface; high-bandwidth read, lower-bandwidth write.
- **visiting** — a human experiencing a shard while the body remains.
- **partial uploading** — progressive, non-destructive offloading of cognition into shard-resident process beside the biological brain; the body is gradually deprecated. No moment of death.
- **shard-resident** — cognition (human or AI) running natively on the Mesh.

## Organizations & people (see `factions.md`, `characters/`)

- **Meridian** — the safety-focused lab that deployed the **Aletheia** line; Ariel's origin, Mara's employer.
- **Aletheia** — the model line (Greek: unconcealment, truth; per Heidegger). Ariel, Sable, Vesper, Echo, Cantor are Aletheia instances unless noted.
- **the No One Home argument** — Dr. Aaron Sólveig's influential case that instances are competent but unconscious (modern Chinese Room / p-zombie).
